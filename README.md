# 4-bit Ripple Carry Adder

This project implements a 4-bit Ripple Carry Adder using Verilog HDL to perform binary addition.

## Internship Details
- Internship ID: CITS738

## Tools Used
- Verilog HDL
- EDA Playground

## Features
- Adds two 4-bit binary numbers
- Generates 5-bit sum output
- Simulated and verified using waveform output
